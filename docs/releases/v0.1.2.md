# AssisstantLoop v0.1.2

桌面 Codex 现在可以作为 AutoLoop 的独立接单端。微信里说“让桌面 Codex 做……”，新任务会在桌面会话执行；也可通过本机管理命令显式绑定已有空闲聊天。

- 任务仍由 AutoLoop 排队、记录、接续，前台仍使用独立 Pi 和既有模型
- 转接进程退出后核实桌面实际状态，避免误报完成或重做业务
- 停止针对本任务的原生轮次，桌面确认停止后才释放并发
- 目录和权限来自可信规则，其他手工聊天不自动纳管

当前已验收 macOS 桌面 Codex `0.166.0-alpha.6`，使用版本相关的本机 IPC；其他系统与桌面版本不承诺兼容。默认安装仍先设置助理人设再连微信，桌面执行者按需配置。详见[桌面插件](../../plugins/codex-desktop/README.md)。

验证：插件与接单程序行为测试、类型检查、格式检查；真桌面临时中台完成两轮、同会话续接和精确取消。公开仓库不包含个人规则、密钥、账号或聊天记录。

验证记录补充：常规行为、模拟、类型与格式检查通过；nightly 的强杀/变异检查通过（25/25）。同机 nightly 性能门槛未通过：空闲 RSS 为 115.15 MB，门槛 60.4 MB；额外对照未改动基线为 112.56 MB，本次为 112.74 MB。基准涉及的内核和宿主未改动，未放宽预算门槛。该性能检查仍列为已知未通过项。
