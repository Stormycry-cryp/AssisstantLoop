# AssisstantLoop v0.1.1

补齐通用人设与个人偏好引导，不包含作者的本地设置。

- 公版附带一份可靠、自然、有一点幽默的助理模板，包含做事、沟通、记忆、隐私和相处边界。
- 模板没有作者的名字、使用者身份、个人经历或运行记录。
- 首次安装先选简洁、专业或温和，再设置名字、称呼，并可补充职责、性格和相处偏好。
- 用户自己的内容仅写在本机 assistant.json 与 persona.md；程序更新不覆盖。
- 可用 `--preferences` 带入用户已经明确的偏好，避免 Agent 与终端重复问同一件事。
- 保留“允许主动汇报，但不反复念叨同一件事”的去重规则。

验证：人设引导、偏好持久化、更新保留与安装卸载回归，快速检查、类型检查和格式检查通过。完整内核验证沿用 v0.1.0 的 338 项通过记录，本次未改变内核和协议。

```sh
curl -fsSL https://raw.githubusercontent.com/Stormycry-cryp/AssisstantLoop/main/install.sh | sh
```

从 v0.1.0 更新会保留已有本机人设，不强行让用户再答一遍。需要重新设置可运行 `assisstantloop persona`。
