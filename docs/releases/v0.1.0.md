# AssisstantLoop v0.1.0

首个公开版本。一个独立、常驻的个人交互助理，用自然中文聊天、转交原话需求、转述后台结果；AutoLoop 继续负责具体任务的派发、续接和记录。

## 这版包含什么

- 先选助理人设，再连接个人微信：简洁直接、专业有条理、温和自然，并设置名字和称呼。
- 本机人设独立保存，可编辑，更新不覆盖；基础人设不包含作者的私人身份与经历。
- 独立 Pi 前台，默认 Agent Plan DeepSeek V4.1 Flash、low 思考，不复用 Codex 登录。
- 微信扫码、本人私聊、图片读取、图片后的文字续接、自然回答与任务进展汇报。
- 允许主动说话；同一回执的结案、提问和摘要去重，没有新信息的普通通知静默处理，不反复催同一件事。
- 独立数据目录与端口；保留完整 AutoLoop 内核、协议、插件、MIT 许可证和上游署名。

## 已验证

- `npm test`：338 项通过，1 项按环境跳过，包含固定种子的模拟与有界检查。
- `npm run typecheck`、`npm run format:check` 通过。
- 公开版安装、更新、卸载通过；自定义人设在更新和卸载后保留。
- 上游核心安装与问答续接试跑通过。
- 真实终端流程：选择风格 → 名字 → 称呼 → 微信可稍后连接。
- 从 npm 全新安装 Pi 运行库后，真实 Agent Plan 调用成功，不依赖作者电脑的 Opus 包装环境。

微信扫码需每位用户自行完成；单元测试使用假模型和假传输，不代表其他人的微信账号已验收。图片、文件、模型额度与平台边界见 README。

## 安装

```sh
curl -fsSL https://raw.githubusercontent.com/Stormycry-cryp/AssisstantLoop/main/install.sh | sh
```

固定源码见本版本 tag；上述命令跟随 main。首次向导默认使用已登录的 Codex CLI。前台需要自己的 Agent Plan 专属 Key，扫码与微信确认由用户完成。
