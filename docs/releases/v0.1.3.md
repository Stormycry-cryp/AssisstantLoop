# AssisstantLoop v0.1.3

修复“说在查、却没回结果”和进度追问误触发新任务的问题，补齐只读观测。

- 单独“？”“结果呢”等直接查询既有状态，不再调用模型重新派单
- 新任务唯一的终态汇报不会因旧阻塞相似被静默丢弃，同轮重复通知仍去重
- 进程检查附带固定只读宿主采样，无需放开执行器整体权限
- 可选观察手动启动的本机 Codex / Pi 会话，区分运行、结束和未确认；观察不自动赋予续接、停止权限
- Pi 观察连接只有 orchestration:read，首次不补发历史，之后的完成通知使用稳定编号去重

会话按本机来源、应用、项目和所选模型分别标注，避免把 Pi 框架名误报成业务 Agent 名。

公开安装默认不开启本机会话观察，启用方式和容量边界见[微信说明](../../plugins/weixin/README.md#本机手工会话与进程读取)。源码不含作者账号、会话、凭据或本机配置。
